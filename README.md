# Поставка заготовок — лабораторные работы по дисциплине «Разработка информационных систем»

Приложение на Flask с локальной PostgreSQL. Зависимости перечислены в `requirements.txt`.

- [Вариант 4: текст фотографии](docs/course/variant-4.md).
- [Отчёт лабораторной работы № 2: авторизация, запуск и проверки](docs/course/lab2/report.md).
- [Отчёт лабораторной работы № 1, исходный вариант «Супермаркет»](docs/course/lab1/report.md).

Для варианта 4 используется новая локальная база PostgreSQL `workpieces`. Схема первой лабораторной «Супермаркет» с новой схемой несовместима. Создать отдельную БД и выполнить скрипты:

```sh
createdb -U postgres workpieces
psql -U postgres -d workpieces -v ON_ERROR_STOP=1 -f app/db/db_data/tables.sql
psql -U postgres -d workpieces -v ON_ERROR_STOP=1 -f app/db/db_data/input_data.sql
psql -U postgres -d workpieces -v ON_ERROR_STOP=1 -f app/db/db_data/auth.sql
```

Параметры подключения разместить в `app/data/db_config.json` по примеру `app/data/db_config.example.json`, указав своего пользователя PostgreSQL и пароль. SQL-скрипты создания схемы и начальных данных выполняются один раз для пустой БД; `auth.sql` допускает повторное выполнение.

Схема содержит типы заготовок, заготовки (вес в кг и материал), остатки отдельно по каждой цене, поставщиков с датой договора, накладные с общей суммой и строки накладных. Начальные данные относятся к 2020 году. Остатки и даты их обновления при заполнении рассчитаны по строкам накладных. Процедура и триггер из индивидуального задания пока не реализованы; приложение ЛР‑2 выполняет чтение данных и авторизацию.

Доступны три запроса: заготовки выбранного типа, поставщики выбранного города, накладные поставщика за период. Например: тип `1`, город `Москва`, поставщик `1` за `2020-03-01` — `2020-03-31`. В выдаче заготовок одна заготовка отображается отдельно для каждой цены.

Учебная учётная запись: логин `admin`, пароль `admin`.

```sh
python -m flask --app app.main_menu run
```

```sh
python -m unittest discover -v
```

Для интеграционных тестов задать `LAB1_TEST_DB_CONFIG` — путь к JSON-конфигурации доступной PostgreSQL. Тесты создают и удаляют собственную временную схему.

Учебная учётная запись кладовщика: `storekeeper` / `storekeeper`. Доступны главное меню и выход; доступ к запросам запрещён.
