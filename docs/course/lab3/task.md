# Лабораторная работа №3. Работа с запросами и основной бизнес-процесс.

Лабораторная работа выполняется для базы данных индивидуального варианта студента.

## Задание.

1. Разработать карточку варианта использования Работа с запросами.
   Предусмотреть возможность выполнения нескольких запросов.
   Выбор конкретного запроса организовать через меню запросов.

   - Разработать сценарий работы с параметризованным запросом
   - Разработать системные диаграммы последовательности для меню запросов и для любого параметризованного запроса.
   - Разработать требования к шаблонам.

2. Разработать карточку варианта использования Основной бизнес процесс. Название бизнес процесса для конкретного варианта согласовать с преподавателем.

   - Разработать сценарий основного бизнес процесса
   - Разработать системную диаграмму последовательности для основного бизнес процесса
   - Разработать структуры данных, поддерживающих работу Основного бизнес процесса.
   - Разработать требования к шаблонам.

3. Реализовать оба варианта использования на языке Python.
4. Подключить к обоим реализованным вариантам использования авторизацию внутренних пользователей.

## Содержание отчета.

1. Системная диаграмма вариантов использования для индивидуального варианта.
2. Карточка варианта использования Основной бизнес процесс, включая

   - главный успешный сценарий и исключения,
   - системную диаграмму последовательности
   - описание структур данных, поддерживающих работу Основного бизнес процесса.
   - требования ко всем шаблонам этого варианта использования.

3. Карточка варианта использования Работа с запросами, включая

   - главный успешный сценарий и исключения,
   - системную диаграмму последовательности
   - требования ко всем шаблонам этого варианта использования.
