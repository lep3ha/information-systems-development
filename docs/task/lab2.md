# Лабораторная работа №2. Авторизация внутренних пользователей. 

Лабораторная работа выполняется для базы данных индивидуального варианта студента.

## Задание.
1.	Описать систему авторизации внутренних пользователей.
2.	Разработать blueprint для авторизации внутренних пользователей.  При успешной авторизации blueprint должен сохранять параметры пользователя в сессии и передавать управление в Главное меню информационной системы.
3.	Разработать Главное меню информационной системы для индивидуального варианта, позволяющее пользователю перейти к выполнению запросов или закончить работу с системой. Главное меню должно использовать декоратор login_required для проверки авторизации пользователя. 
4.	Разработать декоратор group_required, который будет добавлять к декорируемой функции проверку. Проверка должна будет установить, разрешено ли группе, к которой относится конечный пользователь, доступ к декорируемой функции.  Такая проверка должна использовать словарь, отображающий системную диаграмму вариантов использования для индивидуального варианта студента.
5.	Подготовиться к Рубежному контролю 2.

## Содержание отчета.
1.	Системная диаграмма вариантов использования для индивидуального варианта.
2.	Словесное описание системы авторизации внутренних пользователей.
3.	Карточка Главного меню, включая главный успешный сценарий и исключения, системную диаграмму последовательности, учитывающую использование декоратора login_required требования к шаблону.
4.	Карточка варианта использования «Авторизация», включая главный успешный сценарий и исключения, системную диаграмму последовательности требования ко всем шаблонам этого варианта использования.
