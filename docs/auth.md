# Авторизация внутренних пользователей

Полное описание системы, согласованные группы и права, сценарии и диаграммы находятся в [отчёте лабораторной работы № 2](course/lab2/report.md).

- `admin`: главное меню, все запросы, завершение работы.
- `cashier`: главное меню и завершение работы; запросы возвращают HTTP 403.
- Учётные записи хранятся в `internal_user`; пароли — в виде хешей.
- Скрипт `app/db/db_data/auth.sql` создаёт учебную запись `admin` / `admin`.
- Сессия Flask хранится в подписанной cookie браузера. В ней находятся идентификатор и группа пользователя, а также признак постоянной сессии. Подпись защищает целостность, но не шифрует содержимое. Таблица сессий и обработчик её очистки не используются.
- `login_required` защищает главное меню, `group_required` — все обработчики запросов.
- При завершении работы сессия очищается.

Учебная учётная запись кассира: `cashier` / `cashier`. Доступ к запросам запрещён.
